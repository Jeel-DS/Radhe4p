
AI WEBSITE GENERATION PROMPT
===========================

Build a web-based data management system for a diamond processing company named Radhe 4P.

COMPANY BACKGROUND
------------------
Radhe 4P is a diamond processing company.
The company receives diamonds from different dealers, assigns work to workers, and pays workers based on the number and type of diamonds processed.
Diamond prices vary depending on the dealer and diamond type, and prices are controlled by the manager.

USER ROLES
----------
1. Manager
2. Worker

AUTHENTICATION
--------------
- Role-based login system
- Separate dashboards
- Secure access control

WORKER MODULE
-------------
- Daily work request (diamonds count, dealer, diamond type)
- View earnings after manager approval
- View advance/borrow records
- Download daily, monthly, yearly Excel reports

MANAGER MODULE
--------------
- Approve worker requests and assign prices
- Manage dealer-wise diamond prices
- Give advances to workers
- View analytics and history
- Download monthly and yearly Excel reports

COMMON FEATURES
---------------
- Excel download
- Simple UI
- Date filters

DATABASE
--------
Users, Workers, Dealers, Diamond Types, Diamond Prices,
Work Requests, Earnings, Advances, Reports

FINAL GOAL
----------
Create a production-ready internal management system for Radhe 4P.
